# Repository Guidelines

This file is the entry point for agent documentation. Keep it short; detailed guidance belongs under `docs/agent/`.

Before modifying the repository, read:

1. [`docs/agent/rules.md`](docs/agent/rules.md) — mandatory rules for every change.
2. [`docs/agent/project-structure.md`](docs/agent/project-structure.md) — repository layout and ownership boundaries.
3. [`docs/agent/development.md`](docs/agent/development.md) — installation, validation, and testing commands.

Apply the instructions in the most specific `AGENTS.md` if another one exists below the directory being changed. When instructions conflict, the closest applicable `AGENTS.md` takes precedence.
